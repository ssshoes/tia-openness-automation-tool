# Import hik 3050

Wybierz „CSV → hik 3050”, wskaż CSV i projekt albo otwartą sesję Multiuser.
Przykład: `hik_3050_example.csv`. Nazwy oraz numery i adresy IP należy dopasować do projektu.

Nagłówek CSV: `Name;DeviceName;Type;IpAddress;SubnetName;ProfinetNumber;PlcName;GroupName;StartAddress`.
Obsługiwane separatory: średnik, przecinek i tabulator. `Name` określa nazwę elementu DAP, a `DeviceName` nazwę urządzenia, analogicznie do importu Keyence. Puste `DeviceName` lub `0` daje nazwę `Name_DEV`. Puste `Type` lub `0` wybiera domyślny DAP Hikvision podany poniżej; wypełnione `Type` jest przekazywane do TIA.

`StartAddress` podaj tylko w pierwszym wierszu urządzenia: jest wspólnym punktem startowym dla I i Q. Wartości tej kolumny w następnych wierszach są ignorowane, nawet jeśli są wypełnione. Każdy obszar I/Q dostaje pierwszy wolny ciągły zakres od bieżącej pozycji wzwyż. Pozycja przesuwa się o długość obszaru odczytaną z TIA, niezależnie dla I i Q. Import omija zajęte zakresy wszystkich urządzeń projektu, również w grupach. Nie wraca do mniejszych luk przed ostatnio przydzielonym zakresem.

Opcjonalne kolumny `SubnetName` i `PlcName` pozwalają wskazać sieć i sterownik. Gdy są pominięte, wybór sieci i systemu IO działa jak dla Keyence: pierwsza podsieć i jej pierwszy system IO.

`GroupName` wskazuje grupę urządzeń na najwyższym poziomie projektu; brakująca grupa jest tworzona. Pusta wartość lub `0` pozostawia urządzenie bez grupy.

W katalogu TIA musi być zainstalowane urządzenie:
`GSD:GSDML-V2.34-HIKVISION-MV-20210719.XML/DAP/DAP 3`.
Import wykorzystuje obszary I/Q udostępnione po utworzeniu tego DAP. Jeśli DAP wymaga dodatkowego wstawienia modułów, import zatrzyma się z komunikatem o potrzebnych identyfikatorach modułów. Niepełne urządzenie z nieudanej iteracji jest usuwane; wcześniej dodane urządzenia pozostają w projekcie.

Puste `Name` lub `0` kończy listę. Istniejąca nazwa urządzenia przerywa import. Błędny IP lub brak wymaganego numeru/adresu początkowego przerywa import przed tworzeniem urządzeń.
